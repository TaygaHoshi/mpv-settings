# mpv-settings
My settings for mpv 0.35.1. This branch is more default-like and seemingly performs better on weaker hardware. Specs:
- Debian 12
- Intel i5-1335U
- No GPU
- 16GB RAM
- NVMe SSD

### Usage (Linux)
```bash
# Installing:
mv ~/.config/mpv ~/mpv-old # backup old config to your home directory
git clone https://github.com/TaygaHoshi/mpv-settings.git ~/.config/mpv # clone this config to the correct location

# Updating:
cd ~/.config/mpv
git pull
```
